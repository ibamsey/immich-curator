# Architecture Decision Records (ADRs)

Durable decisions for immich-curator. Format inspired by [Michael Nygard’s ADR](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

| [0000](./0000-template.md) | ADR template | — |

## Workflow

1. Propose ADR as `NNNN-short-title.md` with **Status: Proposed**.
2. Review (human or agent); set **Accepted** when implementation may proceed.
3. If superseded, set **Superseded by ADR-XXXX**; do not delete old ADRs.

New ADRs should be referenced from affected implementation plans.
