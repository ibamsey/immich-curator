## Goal

Let the operator add and remove catalog tags on one target asset from the RHS panel. Every Immich call uses the target key. Provenance tags stay attached.

## Prerequisites

- [UC-005](../use-cases/UC-005-ian-assign-tags-to-asset.md) and [DES-007](../designs/DES-007-tag-editor.md) (this documentation pass).
- Target API key configured ([UC-012](../use-cases/UC-012-configure-curator-identity.md)).
- Do not start this plan’s code until that documentation is in place. This file is the plan only.

## Tasks

1. Extend `ImmichTag` with `value`, `parentId`, and optional `color`. Add `src/lib/immich/tags.ts` and route handlers that call **`immichJson` / `immichFetchTarget` only**, matching [`src/app/api/immich/assets/[assetId]/route.ts`](../../src/app/api/immich/assets/[assetId]/route.ts):
   - `GET /api/immich/tags` → `GET /api/tags`
   - `PUT /api/immich/tags` body `{ tags: string[] }` → `PUT /api/tags`
   - `PUT /api/immich/assets/[assetId]/tags` body `{ tagId }` or `{ value }` → upsert when given a path, then `PUT /api/tags/:id/assets`
   - `DELETE /api/immich/assets/[assetId]/tags` → `DELETE /api/tags/:id/assets`
   - Review check: no tag route imports `immichFetchOperator` or `immichJsonOperator`.
   - `DELETE` returns 400 when the tag `value` starts with `import/` or `{immich-go}/`.
2. Panel editor in `AssetCurationPanel`: provenance chips locked, catalog chips removable, combobox of the target’s tags, Enter creates a path and attaches the leaf. Inline errors only. Provenance lock in the client and again on `DELETE` in the route.
3. Refetch asset tags after save. Show `value` anywhere the grid still prints a tag name ([`grid-field-value.ts`](../../src/lib/assets/grid-field-value.ts)).
4. Verify (below).
